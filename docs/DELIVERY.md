# Readlater Android 首版交付

版本：0.1.0，2026-09-21。使用 Flutter 实现共享界面与业务逻辑，Android 原生层负责系统分享、PDF 渲染、文件打开和通知。

## 安装与启动

- 安装 `Readlater-android-arm64.apk`：适用于 ARM64、Android 7.0（API 24）及以上设备。
- 当前 release 包使用开发测试签名，供个人试用；应用商店分发和正式签名不在本次交付内。
- 打开「设置」，填写兼容 Chat Completions 的服务地址、文本模型、多模态模型和个人 API Key；外部研究另需 Tavily 搜索 Key。
- 云端地址使用 HTTPS。未配置模型时仍能保存、离线阅读资料，分析显示待配置。
- 先分享一篇博客，查看观点卡片；RSS 条目需要主动选中才分析。主题可按需综述；外部研究需确认，持续追踪需按主题授权。
- 在设置中导出 ZIP 备份。备份不含密钥，恢复后追踪暂停；卸载前先自行备份。

## 当前交付能力

本地收藏网页、文字、图片和 PDF；RSS 浏览与挑选；个性化总结、观点卡片、资料关联、自动兴趣与主题发现；主题综述、多轮研究、限额追踪、前台恢复补查；本地笔记、偏好、研究记录及 ZIP 备份恢复。网页跳转后的相对图片链接与 RSS 链接已修正，既有订阅条目身份保持稳定。

## 已验证

- 77 项 Flutter 测试通过，静态分析零问题。
- Android 设备集成测试通过，覆盖真实 SQLite/HTTP/PDF 链路，以及图片分析、多轮研究、自动主题发现。
- 未选 RSS 不分析，库内自动主题生成不增加搜索请求。
- 从备份恢复到独立空资料库，重启后正文、分析摘要与附件字节一致。
- 系统文件选择器完成 ZIP 导出和恢复；界面输入的文字资料重启后仍可读取。
- 最新 release APK 已安装；断开内容服务并重启后，收藏正文及示例图片可离线查看。
