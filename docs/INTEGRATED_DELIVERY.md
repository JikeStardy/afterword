设备综合测试首次失败于旧的单条诊断记录假设。V3 分别记录后台包装任务与内部执行任务；测试现同时检查任务成功，并要求恰好一个带供应商调用的执行记录。调用次数、请求响应和脱敏断言均保留，复测通过。

后台专项首次因人工工具往返超过 20 秒切后台窗口而未进入后台，保留失败日志。重跑使用同进程外部协调器，在提交 marker 后 100 毫秒内发出 HOME／锁屏；原测试断言未更改，长文及 PDF 全部通过。该验证不覆盖进程被杀、Doze、通知拒绝或厂商省电矩阵。

诊断设备首轮因 release 构建后使用 `--no-pub` 未恢复测试插件注册，失败于截图接口；按仓库既有说明去掉该选项重跑，两阶段通过。没有更改业务代码或弱化测试。

本轮设备为专用 Android API 36 arm64 模拟器，采用本地模型／搜索夹具；不代表真实供应商回答质量、实体手机厂商后台策略或完整 API 矩阵验收。
