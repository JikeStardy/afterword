# Readlater V2 交付说明

目标版本：**0.2.0+2**。平台：**Android arm64，Android 7.0 / API 24 起**。本轮交付包含 APK、Flutter 源码及说明。最终验证证据与产物清单见下文。

需求依据为 [V2 需求补充](superpowers/specs/2026-09-22-readlater-v2-requirements.md) 和 [实施约定](superpowers/plans/2026-09-22-v2.md)。V1 的 [交付记录](DELIVERY.md)、[验收映射](ACCEPTANCE.md) 和 [实现状态](IMPLEMENTATION_STATUS.md) 保留历史语义。

## 本轮变化

用户确认的 A 阅读页与 B 资料列表、日志页统一使用暖白 `#FAF8F3`、深绿 `#476B4F`、无衬线字体、线性图标与 12dp 控件圆角。阅读页使用原文／分析／笔记标签，已有分析时默认展示分析；正文 17sp、1.7 行距，附件独立展开。资料页提供范围、状态筛选、搜索与单项／长按批量管理。四个底部页面保持浏览状态。阅读页和主题综述按来源表显示引用序号，不在正文展示已识别的内部来源 ID。

归档资料和回收站资料仍可阅读，其历史分析、主题综述与研究记录不被重写。它们不再参与新分析、关联、自动兴趣、综述或研究；有其输入祖先的历史成果同样不能作为新推理输入。应用记录完整资料输入链，与模型返回的引用分开。来源链未知的 V1 成果只读保留，仍有效原文可以重新分析。

从回收站恢复只清除删除状态，保留原归档状态。重复收藏及 RSS 已收藏项显示现有资料状态，不自动复活归档或回收站资料。资料状态改变后，处理会停止后续调用并丢弃迟到结果；这不能撤回已发送的网络请求。

## 回收站与备份

- 回收站默认 7 天，可改为 3 天。启动、恢复到前台及相关维护流程检查到期内容。缩短期限需要确认，确认后立即永久删除按新期限已到期资料；不承诺应用关闭时准时执行。
- 永久删除与清空需要确认。删除该资料及其内含分析后，独立保存的历史主题／研究成果和原来源 ID 仍保留，来源显示已删除；清除相关 RSS 收藏指针和详细日志。无引用受管附件在写入与任务空闲时清理，失败可后续重试。
- ZIP 输出数据版本 2，接受版本 1／2，拒绝未知版本。包含归档资料与未到期回收站、原始附件和历史来源链；删除时间不重置，导入提交前移除到期资料。
- 恢复替换资料库，需要确认；保留当前设备的模型／搜索地址和配置，不导入 API Key，不自动启用追踪授权，关闭详细调试并清空当前诊断日志。换机需重新填写个人密钥。诊断日志单独导出，不包含在资料备份中。

## 日志与隐私

「设置 → 开发者」支持任务类别／状态筛选，查看时间线、步骤、错误、HTTP 状态、模型、请求 ID 与实际 usage，导出全部或单任务日志，确认后清空。研究任务的每轮搜索和模型比较分别记录步骤，并关联相应网络调用。未返回的 usage 不估算。并发及嵌套任务分别关联，重启后未完成任务标记中断；日志存储故障不阻断业务，但显示日志错误。

详细交互默认关闭，仅在主动开启后记录。日志过滤密钥、认证头、Cookie、已知凭据及响应／错误中的回显，不保留图片 Base64；附件仅保留元数据。调试内容仍可能包含个人原文、提示词及模型回答，数据库不提供单独的静态加密保证。

普通任务保留 30 天，详细请求／响应保留 7 天；单个请求或响应最多 256 KiB，截断可见。持久化 JSON 的逻辑容量上限为 50 MiB，超过后删除最早任务，并回收 SQLite 空间。**50 MiB 不是物理文件的严格上限**，数据库结构和索引有额外开销。大量清理时同步 SQLite 整理可能短暂占用界面线程。

## 使用与已知边界

安装及开发命令见 [README](../README.md)。release APK 使用 debug 密钥供个人测试安装，未面向应用商店发行。数据本地保存，模型与搜索使用用户自己的 API Key；本机／局域网服务允许 HTTP，云端地址要求 HTTPS。模型分析会发送所需内容给配置的服务，外部研究仍遵守单次确认或已授予的主题追踪范围和调用上限。

本地 HTTP、SQLite 和设备夹具验证不代表真实供应商回答质量、用户个人密钥兼容性或长期研究效果。微信公众号的登录、风控和正文提取仍有站点限制。系统文件保存位置选择应以设备证据为准，widget 测试不能证明原生文件选择器完整行为。iOS、macOS、账号、同步和视频不属于本轮交付。
