# 视觉细化方案

在独立 worktree 的 `feat/visual-refinement` 分支实现，沿用 V2 暖白 #FAF8F3、深绿 #476B4F、无衬线和 12dp 控件，不添加依赖。

1. 统一标题、正文、辅助文字及控件的配色、行高、边界与选中状态；为空状态增加轻量图形容器与合理阅读宽度。
2. 资料页区分范围与状态筛选，增加当前结果数；列表加强标题、摘要、辅助信息层级，保留紧凑分隔列表与长按多选。
3. 阅读页用标题、辅助信息和分隔线建立起读节奏；RSS 与研究页明确分组标题。
4. 先运行现有 UI 行为基线；扩展有内容的 RSS/研究大字体覆盖、笔记键盘可达性和筛选计数测试，运行 full 并独立审查。使用中文字体生成 Flutter 实际渲染截图进行目视检查。

不改变资料生命周期、研究授权、来源链、存储或网络行为。保留功能分支，不合并 main。
