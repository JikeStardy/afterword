# 长尾狐设计语言

## 形状：一句有下文的曲线

完整狐狸表达好奇和陪伴；环抱长尾像阅读之后继续延伸的线。功能图标延续尾部的弧线、圆润端点和略微上扬的收笔，同时保留常见功能轮廓。搜索仍是放大镜，删除仍是回收桶。避免给每个符号附加狐狸耳朵，也不让装饰抢过操作含义。

| 属性 | 约定 |
| --- | --- |
| 功能画布 | 24 × 24；通常在 3–21 单位安全区内 |
| 描边 | 1.75 单位；圆端、圆连接；随图标等比缩放 |
| 常用大小 | 20 / 24；16 用于紧凑行，32 / 48 用于较大入口 |
| 触控面积 | 后续 App 接入至少 44 × 44；图标画布不等于点击区域 |
| 选中 | 五导航提供独立选中几何；标签与状态语义同时变化 |
| 完整狐狸 | 160 × 160；建议实际呈现至少 48 px，空态建议 120–160 px |
| 安全留白 | 品牌画布包含留白，不将尾尖贴边；保持等比、不拉伸 |

16 px 的 PDF、诊断与研究符号细节较密，正式接入优先用 20/24 px 配合可读标签。当前 16 px 选项用于检查缩小效果，不建议将所有密集符号强制缩至 16 px。品牌狐狸不作为 16 px 操作符号。

## 颜色与状态

深绿 `#476B4F` 搭配暖白 `#FAF8F3`，沿用现有应用主题。默认功能图标使用深绿线条；反白用于深绿表面。红色只用于明确错误／危险状态，不能用“绿色狐狸”代替错误说明。

SVG 使用 `currentColor`，可在外层统一着色。狐狸眼部使用与画布一致的颜色：暖白表面默认 `#FAF8F3`，反白版的眼部为深绿。改用其他底色时通过 `fox({ eyeColor: '#色值' })` 或 `svg(id, { eyeColor: '#色值' })` 同步修改，避免留下异色眼点。导出的品牌文件针对规定的双色表面；不是任意背景上的镂空蒙版。

不可只靠颜色区分“未选中／选中”或“错误／正常”。配合选中几何、文字标签、禁用语义与错误说明。减少透明度的禁用状态只用于真正不能执行的操作，不能隐去重要信息。

## 语义覆盖与替换规则

`coverage.json` 以当前 `lib/` 的真实 `Icons.*` 引用生成，记录原 glyph 到新资产的映射和缺失项。`catalog.json` 为完整资产目录。自动覆盖核对可确认图标名称齐全，不能代替将来逐屏检查布局和交互。

- `circle` 的列表圆点与单选控件不能互换交互语义；使用清单中的独立基础控件资产。
- 同一个 `travel_explore` 在导航、主题、外部研究中复用时，页面标签仍需表达具体用途。
- “移入回收站”“清空回收站”“永久删除”保留不同语义与确认流程；图标不改变现有数据行为。
- “刷新”“重试”“恢复备份”“从回收站恢复”分别使用对应动作，不因轮廓相近而合并业务。
- 隐式返回、展开、单选、复选、溢出菜单与日期／时间入口纳入设计资产；系统控件实际替换留待 App 接入。

## 场景

17 个独立场景覆盖：今日暂无推荐、空书库、空归档、空回收站、无搜索结果、无订阅、订阅无条目、无研究主题、资料／记录缺失、未分析、空日志、启动失败、收录中、分析中、保存成功、暂停和研究完成。

插画用于补充页面文字，不能单独表达异常原因或任务结果。错误详情、重试、添加链接、调整搜索、查看成果等真实入口应由页面提供。无日志不意味着服务已经验证正常；空列表也不代表后台任务完成。

## 动效：动作有开始，也有停下

| 预览 | 时长（1×） | 播放 | 使用时机 |
| --- | --- | --- | --- |
| 见面 · 尾尖轻摆 | 1800 ms | 一次 | 首次进入空态或品牌展示 |
| 收下 · 书页落定 | 1400 ms | 等待时循环 | 保存过程，结束由真实事件驱动 |
| 细读 · 线索流动 | 2400 ms | 等待时循环 | 分析／研究进行中 |
| 收好 · 勾选回应 | 700 ms | 一次 | 收到真实保存成功事件 |
| 等候 · 轻轻出现 | 650 ms | 一次 | 空态进入 |
| 重试 · 温和提醒 | 520 ms | 一次 | 错误反馈，不自动重试业务 |
| 暂停 · 尾巴歇下 | 500 ms | 一次 | 任务切换到暂停 |
| 完成 · 翻到下文 | 1000 ms | 一次 | 收到研究完成事件 |

幅度以轻微的尾尖摆动、短距离书页位移和渐显为主。静态阅读不播放装饰性循环；进度未知时不显示百分比。停止、取消、失败和成功必须由真实任务状态驱动。一次性动画结束保留完整可识别的静态图形。

预览支持播放、暂停、重播与 0.5× / 1× / 1.5×。切换效果时取消旧动画，页面隐藏时停播。系统偏好或手动选择“减少动态”时显示静态状态，避免通过缩短到极快速度变相闪烁。关闭减少动态后由用户再次播放。

## 本轮边界

这些是设计资产和浏览器运行的动效示例。没有改动 App 的导航、控件、业务状态或平台启动图标；未输出 Lottie，也没有宣称 Flutter 中已经播放验证。后续实现需验证平台字体放大、真实触控区域、无障碍标签、主题、生命周期取消及屏幕中的最终观感。
