- 5 个 JS/CJS 文件通过 `node --check`。未新增依赖；本环境没有 ESLint，未声称运行了 ESLint。
- `verify-preview.cjs` 在 Node 24.14.1、Playwright 与本机 Chrome 153.0.8010.53 的独立无头会话中通过。直接使用 `file://`；没有外部 HTTP 请求或页面／控制台错误。
- XML 解析核对静态 SVG 变体；无位图、脚本或内嵌自动动画。无效色值、属性注入输入被拒绝。
- 实际操作搜索、空结果、分类、16/20/24/32/48 尺寸、颜色与导航选中态；下载得到 `today-selected.svg` 文件。
- 8 种动效均检查真实 WAAPI 实例、规定时长和循环次数；播放、暂停、重播、0.5×/1×/1.5×及键盘暂停／恢复正常。暂停就绪后时间不再前进，一次动画完成后停止。
- 手动和运行时系统减少动态设置均使舞台静止；恢复普通偏好后等待用户播放。隐藏页暂停通过浏览器内模拟 `document.hidden` 与 `visibilitychange` 验证，不等同于移动设备后台生命周期验证。
- 320/390 px 视口、180% 根字号无横向溢出。查看主形、全套图标与场景、桌面／移动页面及分析／成功动画帧截图。截图与原始结果保存在忽略目录 `dist/fox-kit-validation/`。
- 项目要求的 `bash tool/check.sh full` 通过：68 个 Dart 文件无需格式修改，Flutter 静态分析无问题，13 个临时 Git 钩子场景和全部 288 项 Flutter 测试通过。首次受 SDK 缓存写入权限限制，获工具审批后完成完整检查。
