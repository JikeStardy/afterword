# 全应用阅读设计

基线：V3 `fdf4655`。实现位于独立分支 `feat/reading-design`；不包含原工作区正在开发的微信抓取恢复功能。

## 设计约定

- 全应用采用“导读 → 连续正文 → 按需核对证据”。结论、解释与重要限制直接可读；长引文和历史兼容内容按需展开。旧数据不会自动重新调用模型。
- 外观提供阅读刊物（默认）、紧凑研究工具、数字杂志。共享导航、内容顺序、授权和操作，改变字体层级、间距及色面；正文基础字号均为17，触控区域不因紧凑模式缩小。
- 今日推荐简化为阅读入口和已处理操作，次要操作集中到菜单；资料列表突出标题与摘录；RSS先展示待挑选内容，订阅管理按需展开；研究区区分主题阅读与执行记录。
- 外观即时保存，模型和搜索配置仍使用原保存按钮。切换外观不会保存未提交的配置草稿。

## 内容兼容

新增分析导读、观点标题和研究章节结构。研究结构规范化后生成兼容全文，后续检索和导出继续可用。缺失新字段的旧记录保持可读，原摘要预览明确标注并可查看全文，缺失短标题使用中性编号，不以截断充当语义总结。

来源链、引用定位、失效状态、任务取消与恢复沿用V3规则；结构化报告附入主题时保留研究来源上下文。

## 验证入口

- `test/reading_appearance_test.dart`：三预设、窄屏大字、切换持久化与表单草稿。
- `test/reading_ui_test.dart`、`test/reading_lists_test.dart`：长文、旧记录、引用和列表交互。
- `test/support/reading_fixture.dart`：12条观点及长解释的离线合成样本。
- `integration_test/reading_design_test.dart`：Android三预设实际画面、阅读滚动、引用往返与文字选择；截图通过已有 `test_driver/device_screenshots.dart` 导出。

最终执行结果及三种风格实际截图见 [验收记录](VALIDATION.md)。合成内容和固定响应不代表真实模型的输出质量；模拟器不代表个人手机或所有厂商设备。
