# 临时 App DEBUG 与内网上传

## 实现约定

- 基于 `feat/personal-insights-background` 的 `fdf4655` 独立实现；不包含其他工作区的界面分支或未提交文档。
- 复用诊断 SQLite，追加会话与结构化事件。默认 INFO，临时 DEBUG 仅驻留当前进程内存；旧模型完整交互开关独立。
- 事件涵盖生命周期、任务、RSS/内容请求、存储和原生后台事件。默认不采集正文；URL 路径摘要及查询值移除，错误和嵌套 JSON 同样脱敏。
- 上传配置在资料备份之外，令牌放入已有安全存储。ZIP 包只含事件、任务摘要及环境，不含模型交互正文。
- 手动导出/上传固定快照，禁止重定向，60 秒总超时；接收端 64 MiB 限制，原子保存、幂等返回 SHA-256 回执。
- SHA-256 使用已有锁定的 crypto 3.0.7，将其从传递依赖显式声明为直接依赖，未增加新包或升级版本。

## 验证与边界

设备测试使用独立模拟器和本机夹具；分两次进程启动验证 DEBUG 采集、部分 RSS 失败、诊断包上传、重启恢复 INFO、配置与记录保留。测试接收端不接入模型或第三方服务。

真实 `aihot.news` 移动网络握手原因仍需用户复现日志，不根据模拟器夹具推断运营商、证书或反爬结论。系统直接杀进程时最后一个批次仍可能未落盘；不承诺采集系统级崩溃或整机 Logcat。

使用说明见 [手机诊断报告接收](../diagnostics.md)。

## 实际验收

- `bash tool/check.sh android` 通过：13 个隔离 Git 场景、199 项 Flutter 测试、格式/静态分析、arm64 release APK 构建；构建未改变依赖锁文件。
- 补充上传超时关闭连接用例后，`bash tool/check.sh full` 再次通过，最终 **200 项 Flutter 测试**；Node 接收端 **8 项 HTTP 测试**及语法检查通过。
- 独立代码、TypeScript/JavaScript、Kotlin 审查通过；修复了嵌套 JSON 正文脱敏、定时落盘、错误容错、私有 RSS 地址标题泄露、清空后异步写回、可选环境读取阻断导出、原生冷启动/调度事件遗漏及事件倒序展示问题。
- Android 36 arm64 专用模拟器：开启 DEBUG、前后台保持、RSS 部分失败、生成诊断包、真实 Node 接收端上传与 SHA-256 回执校验均通过。实际收到 ZIP 包包含 36 个事件、4 个任务，未包含测试私有参数或上传令牌。
- 真正结束进程后再次安装启动测试入口，INFO 恢复、旧 DEBUG 事件、待上传包、上传配置均通过断言。测试使用 `flutter drive --keep-app-running`，避免默认测试清理卸载 App 导致数据删除；两阶段之间显式 `adb shell am force-stop app.readlater.readlater`。
- 人工检查实际主题下的控制区和诊断包预览截图，无布局溢出。另有 320 宽度/1.8 倍字号 Widget 测试。
- 测试上传使用 adb reverse 到电脑回环端口，未验证用户家庭 Wi-Fi 路由器或个人手机。没有真实模型调用或公网部署，未合并 main、发布或上传代码。
