# Readlater V2 需求补充

日期：2026-09-22。目标版本：0.2.0+2，Android 个人自用交付。

本文增补 [V1 需求基线](2026-09-21-readlater-requirements.md)，依据 [V2 实施约定](../plans/2026-09-22-v2.md) 整理本轮范围，不改写 V1 历史验收。用户确认 A 阅读页、B 资料列表与日志页，共用暖白深绿视觉。实现状态和验证证据另见 [V2 交付说明](../../V2_DELIVERY.md)，需求条目本身不表示已经验收。

## 视觉与阅读

| 编号 | 要求 |
| --- | --- |
| V2-UI-01 | 统一暖白 `#FAF8F3`、深绿 `#476B4F`、无衬线字体、线性图标、12dp 控件圆角，采用 A 阅读页与 B 列表／日志布局。 |
| V2-UI-02 | 阅读页提供原文／分析／笔记标签；已有分析默认展示分析，正文 17sp、1.7 行距，主要内容开放排版，附件独立展开。 |
| V2-UI-03 | 紧凑资料列表支持搜索、使用中／已归档／回收站，以及全部／未读／已分析／异常筛选；空范围与无搜索结果分开表达。 |
| V2-UI-04 | 支持单项与长按批量管理；四个底部导航保留页面状态，错误和通知不重叠。320／390／430 宽与大字体、键盘场景须验证主要操作可达。 |

## 资料生命周期与输入边界

| 编号 | 要求 |
| --- | --- |
| V2-LIFE-01 | 归档保留原资料、附件与历史成果，允许阅读；取消归档恢复参与新处理。回收站内容同样可读，禁止新分析和从该资料发起研究。 |
| V2-LIFE-02 | 已归档、回收站、已永久删除资料及依赖其输入的旧成果，不得参与新分析、关联、兴趣推断、综述、研究上下文或研究结果复用。排除已知的归档／回收站来源 URL，避免搜索或缓存间接带回。 |
| V2-LIFE-03 | 应用维护完整输入祖先资料 ID，含偏好贡献，独立于模型选出的引用；未知旧来源为未知，不能猜测为无输入。旧成果保留可读，但未知或失效来源成果不复用。 |
| V2-LIFE-04 | 删除先进入回收站且保留归档时间；恢复只撤销删除，因此原归档资料恢复后仍是归档。永久删除和清空需确认。 |
| V2-LIFE-05 | 回收站默认 7 天，只允许 3／7 天。启动与回到前台清理到期内容；缩短保留期须说明不可逆后果并确认，确认后立即清理按新期限已到期内容。应用关闭时不保证准时清理。 |
| V2-LIFE-06 | 永久删除清除该资料及其内含分析、RSS 收藏指针、相关详细日志和无引用受管附件，保留独立存储的历史主题／研究成果与来源 ID，来源显示已删除；附件清理避开在途写入，不处理任意路径。 |
| V2-LIFE-07 | 生命周期改变使在途处理失效；调用前后和异步写入后检查，丢弃迟到结果，停止后续调用。旧任务不能覆盖重试的新状态，不声称撤回已发送请求。 |
| V2-LIFE-08 | RSS 与重复收藏保留已有归档／回收站状态并允许打开现有项；自动主题失去有效资料支持时暂停。明确确认的兴趣独立保留，不随自动兴趣重算丢失。 |

## 备份与迁移

| 编号 | 要求 |
| --- | --- |
| V2-DATA-01 | 数据输出版本 2，兼容导入版本 1／2，拒绝未知版本；新增状态与设置有兼容默认值，保留未知和显式空输入链的差别。 |
| V2-DATA-02 | 备份包含归档资料与未到期回收站，保留删除时间，不重新起算；导入提交前排除到期资料，清理其 RSS 指针并保留历史来源链。 |
| V2-DATA-03 | 恢复替换资料库需确认，保留当前设备模型／搜索配置，不备份或导入密钥；导入后暂停追踪授权、关闭调试，并清空当前诊断日志。诊断日志独立于资料备份。 |

## 可观察性与调试

| 编号 | 要求 |
| --- | --- |
| V2-LOG-01 | 独立 SQLite 日志记录任务类别、状态、开始结束时间、对象／输入 ID、步骤与并发／嵌套关联。任务失败、中断和取消须如实呈现，日志故障可见且不使业务失败。 |
| V2-LOG-02 | 记录调用模型、HTTP 状态、请求 ID 与服务商实际 usage；缺失则明确未提供，不推算，不呈现不存在的隐藏推理。 |
| V2-LOG-03 | 详细请求／响应默认关闭，用户主动开启后才采集；关闭后不保留在途调用的详细内容。过滤密钥、认证头、Cookie、已知凭据及嵌套字段和回显；图片 Base64 仅保留附件元数据。 |
| V2-LOG-04 | 普通记录保留 30 天，详细交互保留 7 天，总逻辑日志上限 50 MiB；超过清理最早任务并回收空间。单请求／响应限制 256 KiB，标明截断。物理 SQLite 文件存在额外结构开销，不能宣称严格不超过 50 MB。 |
| V2-LOG-05 | 设置→开发者支持类别／状态筛选、详情时间线、请求／响应／用量、导出与确认清空；资料／研究失败可定位相关任务，包括输入关联而无直接对象 ID 的任务。 |
| V2-LOG-06 | 永久删除资料时清除相关详细载荷，并防止在途响应重新写入；清空日志后旧任务不能重新写回被清内容。 |

## 交付与验收

| 编号 | 要求 |
| --- | --- |
| V2-DEL-01 | 交付 Android 0.2.0+2 APK、源码和说明，不新增依赖，不引入账号、同步、视频或跨端交付。保留个人 API Key 与本地／局域网兼容服务使用方式。 |
| V2-DEL-02 | 对生命周期、间接来源污染、在途取消、旧备份、调试脱敏／故障／容量和 UI 管理执行行为回归；记录先失败后修复的证据。 |
| V2-DEL-03 | 运行全量测试、静态分析、Android 构建、设备或模拟器集成与屏幕核对，独立审查问题需有修复／验证闭环。分项报告不得代替完整验收。 |
| V2-DEL-04 | 未配置真实外部模型不阻止本地夹具验收，但须说明真实凭据、服务商兼容性、模型质量和长期效果未验证；未完成项目明确列为待补。 |
