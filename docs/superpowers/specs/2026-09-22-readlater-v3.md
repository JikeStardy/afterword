# Readlater V3：个人知识与后台分析

需求依据：本任务用户确认的《Readlater 下一版：今日推荐、个人知识积累与后台分析》。实现范围 Android，本地保存、BYOK；不自动合并 main 或发布。

## 产品验收

- 五个底部页：今日（默认）、资料、RSS、研究、设置。当天最多五项、稳定列表、理由、跳过/延后/反馈；不自动外搜，禁用来源不得进入推荐。
- 资料处理状态与归档权限分离；浏览不等于完成；旧归档、回收站、来源链排除不变。
- 主题维护背景、目标、限制、个人判断和未解决问题，明确确认与来源；研究可选资料/context，个人笔记参与，修订标记成果过时。
- Insight 包含发现、变化、个人影响、证据、未知及个人反馈。段落/PDF 页定位，不伪造证据。
- 结构化正文、阅读位置/字号、高亮与自动保存批注、PDF 页笔记；重抓保留版本并标记失效锚点。
- 检索正文/笔记/分析/成果，中文排序与片段；独立抓取/补图重试、重复提示、带引用 Markdown 导出。
- RSS 支持保存/跳过/隐藏已处理/批量处理/暂停/退订，未收藏不参与研究。

## 后台及通知

- 前台提交立即启动 dataSync FGS；输入复制到私有目录并持久入队后返回，单队列执行。
- 单缓存 FlutterEngine、单 AppController、单数据库写入者；Activity 销毁不终止执行。后台桥接不能依赖 Activity。
- 长文/PDF 分批 checkpoint；阶段成果、任务状态、checkpoint、通知 outbox 同库事务。取消、生命周期、备份恢复通过 epoch/version 拒绝迟到结果。
- 正常切后台/锁屏继续；系统中断下次打开恢复；取消不恢复。有限网络重试，认证/格式错误不无限重试；请求尝试与研究预算不重置，响应丢失提示可能重复费用。
- 运行通知含进度/取消，完成/失败通知支持冷启动定位，多项汇总；权限拒绝不阻止分析。
- 四类通知通道：运行、结果、每日、研究。每日默认本地20:00可改/关、非准点、无候选不发、每日去重。
- JobScheduler 的 digestOnly 入口仅本地计算，不恢复网络任务、不触发追踪；时区/时间变化重排，仅 digest 排期跨重启。
- 系统服务时限、Doze/厂商限制显式处理，任务期限唤醒锁必释放；不承诺系统强停后继续。

## 数据与验证

- 数据 v3 读取 v1/v2/v3，拒绝未知，迁移事务失败回滚；旧资料及来源语义不丢失。
- 备份只含业务数据，不含运行队列/checkpoint/outbox/密钥。恢复暂停追踪、保留当前端点，处理中且无对应任务的条目可手动重试。
- 单元/Widget/真实 SQLite 集成及 Android 前后台设备验证，覆盖迁移、授权、取消/迟到、checkpoint、预算、通知去重/拒绝/冷启动、digest 零网络、小屏/大字体。
- full、android、独立审查；记录实际可用设备/API，不把夹具结果声明为真实模型质量验证。

## 实施次序

1. 模型与事务任务骨架；2. 原生后台/通知；3. 知识/阅读/检索；4. 今日/RSS/反馈；5. 集成、审查和交付。

架构/批判审查已在规划阶段分别通过。最大风险及防线：整库覆盖（单写入者/事务）、重复付费（阶段记录/预算）、每日调度误触网络（独立 digestOnly 权限）。
