# 有来源的知识对话与长资料补读

日期：2026-10-02。状态：用户已批准实施。实施顺序见 [实施计划](../plans/2026-10-02-knowledge-dialogue.md)。

## 目标

用户需要围绕完整资料持续提问、追问和修正认识，避免每轮重发大量材料和固定取前 4000 字符。原文完整保留，按问题检索块内窗口，必要时自动补读；理解结果可复用，知识更新以差异提案交由用户确认。

## 内容与输入

首版支持网页／文本、PDF、独立图片。长文本与 PDF 按稳定窗口或页范围形成中立分段摘要，再层次合并；摘要只依赖来源内容，不带个人笔记、偏好或历史。缓存身份包含来源 ID、版本、范围、内容指纹和提示词版本。旧带偏好的 v1 检查点继续旧恢复流程，不提升为中立业务摘要。

4000 字符只曾是历史节选预算，不是一篇资料的永久可读上限。问答从全文匹配问题，包括单个超长段落尾部；保留块 ID、UTF-16 偏移和版本，不新增向量依赖。短资料可直接分析，长资料及 PDF 分段理解可持久复用。PDF 每批仅提供本批页面，相关历史只在最终分析中提供。

每问默认最多 5 次模型调用，设置可选 1–20 次；文本、视觉、超时和手动重试在发送前累计，最后一次只能回答。失败后显式重试继续原预算，耗尽后提交新问题。恢复中的不确定请求不自动重发。

每请求序列化文字默认最多 24000 UTF-16 字符，可选 8000–64000；包括 system、协议、JSON、问题、背景、历史、知识、摘要和窗口。这是字符预算，不显示为精确 token 数。文字 UTF-8 硬上限 256 KiB，每张压缩图最多 1 MiB，每请求最多 4 张，整个 HTTP 体最多 8 MiB。原图不改写；Android 归一化到最长边 2000、最多 2000000 像素，GIF 只取首帧。90 秒整体时限覆盖发送及完整响应，取消和超时中止该请求，不关闭另一个通道的共享客户端。

## 对话与知识

入口为阅读页“问这篇资料”、主题页“围绕主题讨论”、研究页“问知识库”，不增加底部导航项。会话可选择来源、重开历史、提问及追问，展示阶段进度后一次呈现完整答案。首版不依赖 streaming。界面显示调用预算、已读范围、原文定位、视觉核验边界、暂停与重试。

模型补读采用受控 JSON 动作：本地 search、readText、readPdf、readImage。控制器仅执行会话范围内有效来源和范围；不给模型任意路径、URL、代码或外部搜索权限。最多一个交互任务和一个后台任务，同一会话只有一个在途轮次，原生媒体操作串行。

新资料及对话均可产生 KnowledgeProposal。提案展示基础内容与新内容，用户可编辑、接受或拒绝。接受时一次事务检查基础修订和全部实际输入的版本／指纹，创建 KnowledgeRevision、移动 Topic.currentKnowledgeRevisionId 并标记提案接受；重复点击幂等，失败不提前发布内存对象。编辑标记 humanEdited，不提升证据可信度。恢复历史版本产生新修订，不删除历史。

已有自动主题综述独立保留，不自动成为“已确认知识”。单资料成功不等待所有主题重生成；相关新来源合并为后台增量提案，旧综述支持手动刷新。ContextEntry 继续作为用户背景，不承接多来源知识页。

## 来源与生命周期

SourceWindow 记录实际本轮提供的来源、版本、块、偏移、文本及指纹。答案必须引用本轮实际窗口，不得因全文中存在同句而接受未发送的引用。视觉证据绑定原附件 SHA256 与 PDF 页，明确未经精确文字核验，模型摘要不得升级为原文证据。

所有实际推理输入记录完整祖先，包含安全历史与已确认知识；指定来源限制全部来源派生内容。归档、回收站、删除、修订或配置变化后停止后续读取并拒绝迟到提交。旧成果保留历史阅读，失效来源不能通过会话历史、知识页或摘要重新进入推理。对话不隐式外部研究或开启持续追踪。

任务采用 Zone 绑定的 JobExecutionContext，交互和后台互不写对方检查点。单个取消不递增全局生命周期；资料生命周期、暂停全部、恢复及销毁继续全局失效。新提交先保存分离快照，再发布增量，保留已有 LibraryItem、Topic 和运行任务对象身份。

## 数据与备份

AppData v4 新增 conversations、conversationTurns、segmentSummaries、knowledgeProposals、knowledgeRevisions，兼容读取 v1–v4，未知版本拒绝。RuntimeState v2 兼容 v1／v2；新任务 v2、旧 v1 检查点保持可读恢复。恢复的在途对话中断，保留 requestPending 和已消耗调用数。

备份含会话和业务知识，不含凭据、运行授权、临时渲染／归一化媒体、base64。原附件依旧属于 items.assets；附件恢复换路径不改变视觉 SHA 身份。历史来源删除后可保留记录并显示不可用。现有研究授权、追踪暂停、日志隐私和备份服务配置保护继续适用。

## 验收

- 长段尾部问题可检索与定位；分析覆盖长资料各段并复用中立缓存。
- PDF 批次不重发历史，最终保留实际页码与附件指纹；图片归一化不修改原图。
- 同会话单轮、双通道并发、单轮取消隔离、整体超时、预算和失败重试均有行为测试。
- 未发送证据、基础知识并发更新、范围外派生内容、来源变更／排除和迟到结果有回归测试。
- 模型和存储迁移、未知版本、备份恢复、保存失败无半提交有测试。
- 320px、1.8 字体、键盘、长回答、重新进入会话和知识差异确认可用。
- full、Android 构建、独立审查及可用专用设备夹具验证；未实测的供应商质量／usage／耗时明确列出。
